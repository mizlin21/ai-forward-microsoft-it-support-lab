# Evidence and Screenshot Guide

## Purpose

This document outlines the recommended evidence and screenshot collection process for the AI-Forward Microsoft IT Support Lab.

The goal is to demonstrate operational workflows, governance processes, AI-assisted support activities, and Microsoft-based administrative simulations in a structured and reviewable format.

## Overview

Evidence artifacts help demonstrate:

- workflow structure
- operational consistency
- governance awareness
- AI-assisted support processes
- PowerShell workflow examples
- documentation quality
- endpoint governance simulations
- support ticket workflows

These artifacts support portfolio presentation and operational case study documentation.

## Recommended Evidence Categories

The following categories are recommended for evidence collection:

- architecture diagrams
- workflow diagrams
- PowerShell execution examples
- ticket triage examples
- escalation workflow examples
- governance documentation
- operational metrics
- endpoint governance simulations
- onboarding and offboarding examples

## Documentation Recommendations

Evidence artifacts should:

- remain organized
- use descriptive filenames
- support workflow explanations
- avoid sensitive information
- remain professionally formatted
- align with governance principles

## Sensitive Information Restrictions

Evidence artifacts should not include:

- passwords
- API keys
- confidential employee information
- real customer information
- production security configurations
- privileged credentials

Placeholder values should be used where appropriate.

## Example Evidence Workflow

```text
Workflow Created
      ↓
Operational Documentation Completed
      ↓
Evidence Screenshots Captured
      ↓
Files Organized and Named
      ↓
Sensitive Information Reviewed
      ↓
Evidence Added to Repository
```
