# Workflow Diagrams

## 1. Employee Onboarding Workflow

```text
New Hire Request
      ↓
Manager Approval
      ↓
Create Entra ID User
      ↓
Assign Microsoft 365 License
      ↓
Assign Department Groups
      ↓
Enroll MFA
      ↓
Prepare Device / Intune Enrollment
      ↓
Send Employee Onboarding Checklist
      ↓
Confirm Access
```

AI Assistance Points

AI can assist by:

- Drafting the onboarding checklist
- Generating welcome instructions
- Summarizing required access
- Creating a standard ticket response
- Drafting PowerShell commands for review

## 3. Support Ticket Triage Workflow

```text
Ticket Submitted
      ↓
AI Summarizes Ticket
      ↓
AI Suggests Category
      ↓
AI Suggests Severity
      ↓
IT Reviews Recommendation
      ↓
Resolve or Escalate
      ↓
Document Outcome
      ↓
Update Knowledge Base
```

AI Assistance Points

AI can assist by:

- Summarizing long tickets
- Identifying common issue patterns
- Suggesting troubleshooting steps
- Drafting employee responses
- Creating knowledge base article drafts

## 4. PowerShell Script Review Workflow

```text
Admin Identifies Repetitive Task
      ↓
AI Generates Script Draft
      ↓
IT Reviews Script
      ↓
Security Check
      ↓
Test in Safe Environment
      ↓
Revise Script
      ↓
Document Usage
      ↓
Approved for Controlled Use
```

AI Assistance Points

AI can assist by:

- Drafting initial scripts
- Explaining script logic
- Adding comments
- Suggesting error handling
- Creating documentation
- Important Control

AI-generated scripts should never be executed without human review.
